# Data

The released tables, their inputs, and the checks run on them. The block
between the `checks` markers is generated by `make manifest` from
[MANIFEST.json](MANIFEST.json); everything else is written by hand.

## Layout

| Path | What it is |
| --- | --- |
| `raw/2015/`, `raw/2022/` | the 141 source PDFs (117 for 2015, 24 for 2022), committed as the official copy |
| `raw/MANIFEST.csv` | path, SHA-256, bytes, pages and origin of every PDF; `make sources` (part of `make check`) verifies them |
| `interim/ocr/<year>/*.jsonl.gz` | one record per page: every text box with pixel coordinates, the ruling lines, the rotation applied, and `engine` (Vision, or `text_layer` where the page image is undecodable Kruti Dev) |
| `interim/ocr/<year>/repairs.jsonl.gz` | second reads: the name column of pages that lost names, and whole pages re-read in strips where Vision missed rows |
| `interim/ocr/<year>/row_rereads.jsonl.gz` | single rows re-read where the gender or caste cell came back empty |
| `2015/mukhiya_results.parquet` | 2015, one row per mukhiya seat, read by this repository's pipeline |
| `2022/mukhiya_results.parquet` | 2022, one row per mukhiya seat |
| `<year>/panchayat_samiti_results.parquet` | samiti seats, a by-product (not audited) |
| `2015/source/mukhiya_reservation_2015.csv` | the pooled repository's earlier parse of 2015, kept only as a cross-check |
| `2022/manual/lohardaga_mukhiya.csv` | Lohardaga's 66 mukhiya seats keyed by hand from pages 3-5 (serial and page on every row) |
| `2022/manual/identifier_corrections.csv` | 5 block/GP numbers fixed from the page image (3 OCR misreads, 2 misprints), each with its evidence |
| `2022/manual/missing_rows.csv` | 1 printed row OCR never saw, keyed from the image |
| `2022/manual/gap_review.csv` | every 2022 GP-number gap or repeat, opened on the page and classified |
| `external/lgd_jharkhand_village_gp.csv` | Jharkhand rows of an LGD village-to-GP file (4,345 GPs) |
| `checks/handcheck_2022.csv` | 30 random 2022 rows transcribed by eye from page images |
| `checks/text_layer_2022.csv` | 2022 rows decoded from five gazettes' Kruti Dev text layer, beside their OCR counterparts |

## Columns (`<year>/mukhiya_results.parquet`, both years)

Names follow the pooled schema of in-rolls/local_elections where a column
exists there.

| Column | Meaning |
| --- | --- |
| `state`, `year`, `district` | `Jharkhand`, election year, district (English) |
| `district_no` | the district's number in the state list (Garhwa 1 … East Singhbhum 24) |
| `block_no` | block number printed in the identifier; per district, and **not stable across years** (Dhanbad renumbered) |
| `block` | block name, Devanagari, where the gazette prints it; null otherwise |
| `block_source` | `identifier`, `panchayat_samiti_rows` (the same gazette prints number and name together), `page_heading`, or `hand_keyed` |
| `gram_panchayat`, `gp_no` | GP name and number as printed |
| `tier`, `tier_local` | `gp_head`, `mukhiya` |
| `caste_reservation` | `ST`, `SC`, `BC` (2015 only: पिछड़ा वर्ग), `NONE`, or `RESERVED` (bare आरक्षित with no category: Khunti 2022, 19 rows; 4 OCR readings in 2015) |
| `open_category` | 2022's "खुली श्रेणी के सीट (Open Category Seat)", the former BC seats; `caste_reservation` is `NONE` |
| `woman_reserved` | 1 महिला, 0 अन्य, null when unread |
| `reservation`, `reservation_raw` | pooled label (`ST Woman`, …) and the two cells in standard Devanagari |
| `winner` | elected person as printed; null when unread or vacant |
| `vacant` | 1 where the gazette prints रिक्त (vacant) for the winner |
| `seat_id_raw`, `row_text_raw` | the identifier cell and the rest of the row as read, unaltered |
| `ocr_min_confidence` | lowest Vision confidence in the row |
| `parse_flags` | problems noticed or fixes applied (below) |
| `entry_method` | `ocr` or `hand_keyed` |
| `script` | `devanagari` |
| `source_path`, `source_page` | the PDF and 1-based page |
| `row_y0`, `row_y1`, `page_rotation` | the row's band in pixels on the page rendered at 200 dpi (Lohardaga 400) and turned by `page_rotation`; `build/handcheck_sheet.py` crops rows this way |

`parse_flags`: `post_unread_tier_from_identifier`, `post_mukhiya_but_identifier_ward`,
`caste_unread`, `woman_unread`, `winner_unread`, `gp_no_unread`,
`woman_from_row_reread`, `caste_from_row_reread`, `corrected_ocr_misread`,
`corrected_source_typo`, `duplicate_key`, and for 2015 `block_no_from_file_name`
(Hazaribagh's per-block files: the file's number is the block's, which the
files that print the block confirm), `block_no_from_heading` and
`block_not_printed` (Deoghar pages 24-25 print bare GP identifiers under no
block; `block_no` is null rather than inferred from position).

## How both tables were read

The same pipeline reads both years: the 2015 results were also published as
Form 23.

1. **OCR first, persisted.** Every page is rendered at 200 dpi and read by
   Apple Vision (`hi-IN`) on-device; sideways or upside-down pages are turned
   upright. Where a 2015 gazette's Kruti Dev font was not embedded, the page
   image itself shows Latin bytes ("vurknoh" for अनीता देवी) and no OCR can
   read it; those pages (all of Palamu, Dhanbad, West Singhbhum, Simdega and
   East Singhbhum 2015, parts of others) take their boxes from the text layer
   instead, decoded from Kruti Dev.
2. **Repairs, cached.** Pages that lost their name column are re-read on a
   crop of it; table pages where far fewer identifiers were found than the page
   has rows are re-read in strips cut at the ruling lines; rows with an empty
   gender or caste cell are re-read alone. Each fills only what was missing and
   flags the row.
3. **Rows** are anchored on the identifier cell, other boxes attached by
   tilt-corrected line, fields read by vocabulary; the post cell decides the
   tier.
4. **Reviewed fixes** from `2022/manual/` are applied last.

## Coverage and known problems

- **2022: 4,334 rows against 4,345 GPs; every shortfall is the gazette's.**
  21 districts match LGD exactly. Sahebganj prints 155 (7 GP numbers skipped
  on the mukhiya pages), Pakur 125 (04/02, 04/20, 04/25 skipped), Chatra 151
  (numbering unbroken, block tails checked). Every gap and repeat was opened on
  the page; `2022/manual/gap_review.csv` records 10 source gaps, 2 misprints,
  9 parser gaps (all fixed) and 3 dropped ward rows.
- **Lohardaga 2022 is hand-keyed.** Its scan defeats OCR, so its 66 seats were
  keyed from pages 3-5. The page prints the right-hand columns about a row out
  of line with the names; seats were paired with names in printed order, which
  every woman-reserved seat confirms (each gets a woman's name, and a shift of
  one row would give 2/2, a महिला seat, to कामील तोपनो). Block names come from
  the same gazette's samiti rows.
- **2015: 4,137 rows.** Source ceilings: Pakur's PDF was produced with the
  identifier column outside the page (the text layer stops at 402 pt of 612),
  so no Pakur 2015 row carries a GP and none is in the table; Simdega's ten
  one-page files hold only GP 1 of each block (10 rows). Districts above the
  LGD count (Palamu 278, Godda 201, Sahebganj 166, Chatra 154) have no repeated
  keys and probably reflect 2015 boundaries; not verified. Giridih (330/344)
  still has gaps in block 4 after the strip re-read.
- **Block names**: 336 rows (2022) and 1,310 (2015) have no printed name the
  parser could tie to the number; the key is the number.
- **Vacant seats**: 3 in 2022, 11 in 2015 (`vacant = 1`).

## Independent checks

- **Hand transcription (2022).** 30 random rows rendered as strips and read by
  eye without the parse in view; 29 scored (the Lohardaga one is now
  hand-keyed): block, GP number, caste and gender 29/29; winners 28/29 exact.
- **Text layer (2022).** Five gazettes decoded from Kruti Dev without OCR:
  caste 1,083/1,083, gender 1,106/1,107 on aligned rows.
- **The ported 2015 table.** The pooled repository's earlier parse of the same
  PDFs (different code) agrees with this one on 3,645 shared keys: caste
  3,609/3,635, gender 3,608/3,613, winner names 0.971 character agreement.
  25 of the 26 caste disagreements are Jamtara, where both parsers first read
  अनु0जन0 जाति (an abbreviation of अनुसूचित जनजाति) as SC. Fixed here: Jamtara
  is 117 ST and 1 unreserved in both years, so the apparent 2015 to 2022 shift
  was a parsing error, not a change.
- **2015 name match.** Of the 4,169 2022 GPs in blocks where 2015 has named
  rows, 85.4% have an exact or near (ratio ≥ 85) match in the same block.
